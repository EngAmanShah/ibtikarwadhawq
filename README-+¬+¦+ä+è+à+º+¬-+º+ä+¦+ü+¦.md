# لوحة تحكم موقع ابتكار وذوق — طريقة الرفع والتثبيت

## 1) رفع الملفات
- اضغط محتويات هذا المجلد (dashboard) في ملف ZIP.
- من لوحة الاستضافة (cPanel ← File Manager) ارفع الملف داخل `public_html` وفك الضغط.
- احذف ملفات الموقع الثابت القديمة (index.html والمجلدات about / services / documents / contact) لأن الموقع أصبح يعمل من لوحة التحكم.
- (الأفضل إن أمكن): اجعل الـ Document Root للدومين يشير إلى المجلد `public`. وإن لم يكن ممكنًا فملف `.htaccess` الموجود يتولى التوجيه تلقائيًا.

## 2) قاعدة البيانات
- cPanel ← MySQL Databases: أنشئ قاعدة بيانات + مستخدم، وأعطه كل الصلاحيات (ALL PRIVILEGES).

## 3) التثبيت من المتصفح
- افتح الدومين — سيظهر معالج التثبيت تلقائيًا.
- اتبع الخطوات: فحص الخادم ← بيانات قاعدة البيانات ← حساب المدير ← تم.
- سيتم نقل كل محتوى الموقع الحالي تلقائيًا.

## 4) الدخول
- لوحة التحكم: `https://الدومين/admin`

## المتطلبات
- PHP 8.2 أو أحدث، MySQL 5.7+ أو MariaDB 10.3+
- إضافات: pdo_mysql, mbstring, openssl, fileinfo, xml, ctype, bcmath (و GD لضغط الصور).
- صلاحية كتابة على: `storage`, `bootstrap/cache`, `public/uploads`, والمجلد الرئيسي (لإنشاء ملف .env).

## إعادة التثبيت
احذف الملف `storage/app/installed.lock` ثم افتح الدومين (تحذير: يمسح كل البيانات).

## ضبط الظهور في جوجل (SEO) بعد الرفع
1. من لوحة التحكم ← «الظهور في جوجل (SEO)» ← «رابط الموقع الأساسي»: تأكد أنه النطاق الرسمي
   `https://ibtikarwadhawq.com` (وليس رابط معاينة الاستضافة). الكود يتجاهل تلقائيًا أي نطاق
   معاينة أو localhost ويستخدم نطاق الطلب الحقيقي، لكن ضبطه يدويًا أنظف.
2. بعد رفع التحديث شغّل `php artisan migrate` مرة واحدة لتصحيح الرابط المخزّن في قاعدة البيانات.
3. تأكد من ظهور `https://ibtikarwadhawq.com/sitemap.xml` و `https://ibtikarwadhawq.com/llms.txt`.
4. أرسل ملف `sitemap.xml` من Google Search Console، واطلب فحص الصفحة الرئيسية للتأكد من أن
   «الرابط الأساسي (Canonical)» هو نطاقك الرسمي.
5. أي محتوى جديد يُضاف من لوحة التحكم: الصور تُضغط تلقائيًا إلى WebP وتُنشأ نسخ مصغّرة
   (480/768/1200) لاستخدامها في `srcset`، فلا حاجة لأي خطوة يدوية.
   لإنشاء النسخ المصغّرة لصور قديمة: `php artisan assets:variants`.
